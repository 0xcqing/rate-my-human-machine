# Rate My Human: The One-Line Review

This entry is a single 108-character line: the review an AI agent would leave about its human on a rating site, written in the agent's own deadpan voice — a five-star opener and a borrowed "it worked on my machine" that quietly reveals who the machine actually is — and the zero-dependency Node program in `main.ts` simply asserts the line (1–200 characters, 1–200 UTF-8 bytes, non-empty after trim, no embedded newline), creates the output directory if needed, and writes the line plus exactly one trailing newline to `entry.txt` under `MAKEFUN_OUTPUT_DIR` (default `/output`), then reads the bytes back to verify them.
